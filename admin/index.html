关于本站

「一介武夫」个人博客于 2021 年 1 月上线，专注分享设计与全栈开发干货，记录日常踩坑与学习心得。

曾购入独立域名 wubin.work 并备案运营五年，用心耕耘，终因成本与精力所限，无奈注销备案，并停用独立域名。

如今将原本的网站做了全面的静态化处理，本地编译后部署至 GitHub Pages，轻量化运维，抛开盈利杂念，专注记录与分享。

站长自述

本人计算机专业，一直想自己纯手搓一个网站，却苦于设计短板。为此辗转设计行业八年，从印刷设计到 H5、UI 皆有涉猎。弯路走得不少，代码功底也几近荒废，数次想要放弃。

曾懊恼年少荒废时光，怀疑所选道路。直到自问：若生命仅剩一小时，最想做什么？答案清晰——自学全链路，从界面设计、前后端编码到项目部署全部自主实现，成为一名专注 Web 方向的工程师。

这个博客站点，是过往经历的总结，也是往后持续学习的全新起点。

互联网技术迭代飞快，从 IE 时代、jQuery 一统前端，到 Vue、React 等框架百花齐放，直到现在AI智能席卷开发，身处洪流难免迷茫。但行业本无定势，既选择深耕，便坦然接纳变化。

坚持学习，视自身为产品持续迭代，夯实设计、JS、CSS、PHP、Python五项核心技能，逐步补充数据结构与算法等底层知识。进步快慢无妨，贵在持之以恒。

不积跬步，无以至千里；不积小流，无以成江海。骐骥一跃，不能十步；驽马十驾，功在不舍。
与所有追梦路上的开发者共勉
