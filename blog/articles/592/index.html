PHP中关于获取文件时间信息的三个函数fileatime()、filectime()、filemtime()区别

5970次阅读 411人点赞 作者: WuBin 发布时间: 2025-03-27 14:58:02
扫码到手机查看

区别介绍

filemtime() - 文件内容修改时间（Modification Time）

  • - 返回文件内容最后被修改的时间戳
  • - 当文件内容被修改时会更新
  • - 最常用于判断文件是否需要更新或缓存是否过期

filectime() - 文件状态改变时间（Change Time）

  • - Windows：返回文件创建时间
  • - Unix/Linux：返回文件状态最后改变的时间
  • - 修改文件权限、所有者、链接等属性时会更新
  • - 修改文件内容也会更新这个时间

fileatime() - 文件访问时间（Access Time）

  • - 返回文件最后被访问（读取）的时间戳
  • - 读取文件内容时会更新
  • - 在某些系统中可能被禁用以提高性能
  • - 最不常用，因为频繁访问会导致这个时间频繁更新

举例

$file = 'test.txt';

// 写入新内容
file_put_contents($file, 'hello');
// filemtime 和 filectime 都会更新

// 修改文件权限
chmod($file, 0644);
// 只有 filectime 会更新

// 读取文件内容
file_get_contents($file);
// 只有 fileatime 会更新
在缓存过期判断场景中，通常使用 filemtime() ，因为它最能反映文件内容的更新状态。

对于缓存文件的过期判断，我们通常更关心文件内容的最后修改时间，所以使用 filemtime() 更准确。

再引用一段CDN上面的描述：

1、fileatime()

int fileatime(string filename)：fileatime()函数返回filename最后访问的时间，这里的最后访问是指每当一个文件的数据块被读取。采用UNIX时间戳格式，有错误时返回FALSE。

2、filectime()

int filectime(string filename)：filectime()函数返回filename最后改变的时间，这里的最后改变是指指定文件 filename 的 inode 最后改变时间，其中inode （索引节点）用来存放档案及目录的基本信息包含时间、档名、使用者及群组等。采用UNIX时间戳格式，有错误时返回FALSE。

3、filemtime()

int filemtime(string filename)：filemtime()函数返回filename最后修改的时间，最后修改指的是文件的内容改变。采用UNIX时间戳格式，有错误时返回FALSE。
