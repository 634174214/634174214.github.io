url()助手函数

https://www.kancloud.cn/manual/thinkphp6_0/1037508

系统提供了一个url助手函数用于完成相同的功能，例如：

url('index/blog/read', ['id'=>5])
    ->suffix('html')
    ->domain(true)
    ->root('/index.php');

这个方法可以用于模板中，比如

<a href="{:url('flink/del',array('id'=>$vo.id))}">删除</a>

最终渲染出来的地址就是：href="/tp6-eshop/code/qingadmin/flink/del.html?id=2"

末尾带的del.html与url_html_suffix设置有关，设置在config/route.php中

模板语法 {:函数()}含义

{:xxx}：**执行 PHP 表达式并输出结果，
不管里面是 PHP 原生函数`date()`，还是 TP 自定义助手函数`url()`，都要用 `{:}` 开头，不然原样输出。
- {date('Y-m-d', $vo.time)} → 没有，原样打印文本
- {:date('Y-m-d', $vo.time)} → 执行表达式
- {:url('fapiao/add')} → : 执行 TP 的 url 助手函数

{:函数名(参数)}：直接调用函数（适合 url、date 等），必须加冒号{:}

查

查询https://www.kancloud.cn/manual/thinkphp6_0/1037533

查询多个数据（数据集）使用select方法：

Db::table('think_user')->where('status', 1)->select();
最终生成的SQL语句可能是：
SELECT * FROM `think_user` WHERE `status` = 1
select 方法查询结果是一个数据集对象，如果需要转换为数组可以使用
Db::table('think_user')->where('status',1)->select()->toArray();

如果设置了数据表前缀参数的话，可以使用（table是表全名，name是除去表的前缀，表前缀在config/database.php中prefix设置）

Db::name('user')->where('id', 1)->find();
Db::name('user')->where('status', 1)->select();

查询某个字段的值可以用

/ 返回某个字段的值
Db::table('think_user')->where('id', 1)->value('name');

value方法查询结果不存在，返回 null。比如判断输入的关键词内容有没有重复的

$keyword = input('name');
$id = Db::name('search')->where('name', $keyword)->value('id');
 if($id) {
      return appCommonAlert('不要重复添加', 'index', 5, 3);
}
数据表中如果查询到了id，代表关键词重复了，就不能重复输入

关于field

https://www.kancloud.cn/manual/thinkphp6_0/1037542

在查询操作中field方法是使用最频繁的。

Db::table('user')->field('id,title,content')->select();

里使用field方法指定了查询的结果集中包含id,title,content三个字段的值。执行的SQL相当于：

SELECTid,title,contentFROMuser

可以给某个字段设置别名，例如：

Db::table('user')->field('id,nickname as name')->select();
执行的SQL语句相当于：

SELECT id,nicknameasnameFROMuser

获取所有字段

Db::table('user')->select();
Db::table('user')->field('*')->select();
上面的用法是等效的，都相当于执行SQL：
SELECT *FROMuser

用于写入

除了查询操作之外，field方法还有一个非常重要的安全功能--字段合法性检测。field方法结合数据库的写入方法使用就可以完成表单提交的字段合法性检测，如果我们在表单提交的处理方法中使用了：

Db::table('user')->field('title,email,content')->insert($data);

即表示表单中的合法字段只有title,email和content字段，无论用户通过什么手段更改或者添加了浏览器的提交字段，都会直接屏蔽。因为，其他所有字段我们都不希望由用户提交来决定，你可以通过自动完成功能定义额外需要自动写入的字段。

where用法

https://www.kancloud.cn/manual/thinkphp6_0/1037539

比如使用where执行搜索

 $where = [];
        $searchkey = input('searchkey') ? input('searchkey') : '';
        if($searchkey) {
            $where[] = [
                'title',
                'like', 
                '%' . $searchkey . '%'
            ];
        }

        // 所有数据
$ruleData = Db::name('auth_rule')
                            ->where('status', 1)
                            ->where($where)
                            ->select()

where有多种查询方式，表达式查询、数组（关联数组）、数组（索引数组）、字符串、字符串预处理。

其中表达式查询最常用

where('id', 1)   等价于 where('id', '=', 1) 
Db::table('think_user')
    ->where('id','>',1)
    ->where('name','thinkphp')
    ->select();
等价于
SELECT * FROM think_user WHERE id > 1 AND name = 'thinkphp'

数组（关联数组）主要用于等值AND条件。

Db::table('think_user')->where([
   'name'   =>  'thinkphp',
    'status' =>	1
])->select(); 
等价 SELECT * FROM think_user WHERE `name`='thinkphp' AND status = 1

数组（索引数组）量设置查询条件

Db::table('think_user')->where([
	['name','=','thinkphp'],
    ['status','=',1]
])->select(); 
等价于
SELECT * FROM think_user WHERE `name`='thinkphp' AND status = 1

以及本例中，用的就是索引数组

$where[] = [
    'title', 'like', '%' . $searchkey . '%'
];
// 此时 $where = [ ['title', 'like', '%xxxx%'] ]
Db::table('xx')->where($where)->select();
SELECT * FROM xx WHERE title LIKE '%xxxx%'

字符串预处理

Db::table('think_user')
    ->whereRaw(
        "id=:id and username=:name", 
        ['id' => 1 , 'name' => 'thinkphp']
    )
    ->select();

一般情况下数组方法足够。

多个where查询

$authRuleData = Db::name('auth_rule')

相当于whereparent_id =0AND status =1

insert方法添加数据成功返回添加成功的条数，通常情况返回 1，如果你的数据表里面没有foo或者bar字段，那么就会抛出异常。

删

当id设置为表的主键的时候，可以用下面的方法删除：

$res = Db::name($dbname)->delete($id);

上面这个删除有可能会报错。 Db::name($dbname)->delete($id) 这种写法依赖 ThinkPHP 自动将传入的值解析为主键条件。如果目标表 $dbname 对应的数据表没有设置主键，或者主键名不是默认的 id，框架就无法执行。会抛出错误：报错了 没有条件不会执行删除操作。

建议改为：

$res = Db::table($dbname)->where('id', $id)->delete();

基本循环和判断

首先在控制器中，传入数据

public function index()
    {
        $configData1 = DB::name('xxx')->where('xxx', 1)->select();
        return view('', [
            'configData1' => $configData1
        ]);
    }

然后模板中渲染

{volist name="$configData1" id="vo"}
<div class="row cl">

	<label class="form-label col-xs-4 col-sm-2">

		<span class="c-red"></span>

		{$vo.cname}：</label>

	<div class="formControls col-xs-8 col-sm-9">

		{if condition="$vo.field_type eq 1"}
		<input type="text"  name="{$vo.ename}" value="{$vo.value}" class="input-text">
		{else}
		<textarea class="textarea" name="{$vo.id}">{$vo.value}</textarea>
		{/if}
	</div>

</div>
{/volist}

注意id="vo" 起什么都行，相当于每一项的遍历项。

如上面例子，eq是==，同样可以改成

{if condition="$vo.field_type == 1"}
	<input type="text"  name="{$vo.id}" value="{$vo.value}" class="input-text">
{/if}
{if condition="$vo.field_type == 2"}
	<textarea class="textarea" name="{$vo.id}">{$vo.value}</textarea>
{/if}

模板一个大数组中判断是否有子数组

 {if condition='$vo.children'}
   {volist name="$vo.children" id="vo1"}... {/volist}
 {/if}

{if condition="..."}的作用是在模板（HTML）中进行条件判断，从而控制页面上不同内容的显示与隐藏。比如上面的就是判断外层大循环中某个字段是否有值。

条件判断：condition 属性里面写的是判断条件（类似于原生 PHP 里的表达式）。当条件成立（返回 true）时，就会输出 {if} 和 {/if} 之间的 HTML 内容。

<!-- 假设后端传过来一个 $user.sex 变量，1代表男，0代表女 -->
{if condition="$user.sex eq 1"}
    <span>先生</span>
{else /}
    <span>女士</span>
{/if}

同样的还可以使用原生php

{php}
     if(in_array($vo['id'], [1,2,3])){ echo 'checked'; }
{/php}

在父类中进行模板赋值

模板赋值：https://www.kancloud.cn/manual/thinkphp6_0/1037609

比如现在有个父类控制器

// controller/Base.php
class Base extends BaseController {...}

// controller/Other.php
class Other extends Base {
    return view('', [
       'data' => ....
    ]);
}

现在比如有个变量，用户登录的用户名，需要在多个控制器中的模板中渲染一样的数据

<li>用户名：{$loginUser}</li>

这时候给每个控制器模板渲染中单独添加一个 $loginUser 变量肯定很啰嗦，这时候就可以在父类中添加一个统一的模板赋值

use think\facade\View;
class Base extends BaseController
{
    public function initialize()
    {
        // echo '我是base';
        $loginAdmin = session('adminSessionData');
        // 模板赋值 https://www.kancloud.cn/manual/thinkphp6_0/1037609
        // 在公共父类上面 通过模板赋值的方式 将用户名传递过去
        View::assign('loginUser',  $loginAdmin['user_name']);
    }
...
}

这样只要是继承了Base父类的子类，所渲染的模板中都会自动添加这个loginUser的变量，可以直接用。

在 ThinkPHP 的控制器里，initialize()方法会在控制器实例化之后、调用具体操作方法之前自动执行，你不需要手动调用它。

默认情况下 controller/AuthGroup.php控制器

中间件

https://www.kancloud.cn/manual/thinkphp6_0/1037493

安装中间件，并生成一个Check.php的中间件文件

php think make:middleware Check

执行之后，会在app目录下生成一个middleware/Check.php的目录，注意，app目录下的是叫做全局中间件，如果要做应用中间件，就是对某个目录下的应用生效，就要放到对应的目录中，比如demo里面。注意要同时移动app/middleware目录和复制app/middleware.php文件 都一起移动到子应用demo目录中。

app/middleware.php 里面负责开启session，不开启session会导致验证码怎么验证都是false，这个文件不能删除

开启应用中间件

app/demo/middleware.php 中必须要开启，中间件才能生效

return [
    // 全局请求缓存
    // \think\middleware\CheckRequestCache::class,
    // 多语言加载
    // \think\middleware\LoadLangPack::class,
    // Session初始化
    \think\middleware\SessionInit::class,
    // 启用这个目录下的中间件 用来实现用户登录验证 必须加这么句话才能生效
    加这句话 \app\demo\middleware\Check::class
];

在中间件中添加前置验证（会在所有请求之前，进行验证，可以用于登录验证middleware/Check.php）

<?php
declare (strict_types = 1);
namespace app\qingadmin\middleware;
class Check
{
    /**
     * 处理请求
     *
     * @param \think\Request $request
     * @param \Closure       $next
     * @return Response
     */

    // 前置中间件 
    /**
     * 在执行后台首页之前 http://localhost/tp6-eshop/code/qingadmin/ 先执行业务逻辑 适合用来判断登录
     */
    public function handle($request, \Closure $next)
    {

        // halt($request->pathinfo());
        // 如果判断session为空 那么就代表没登录
        // 这个中间件会对qingadmin\controller中所有控制器运行，像下面的跳转，如果判断没登录就会跳转到qingadmin/login/index，
        // qingadmin/login/index又会重新判断是不是空 会导致来回重定向
        // 所以需要判断当前访问的页面是不是login 来判断是不是登录页 通过$request里面的patshtinfo()方法 pref_match('/login/', $request->pathinfo() 存在login返回true 所以只有不存在时候才跳转
        if(empty(session('adminSessionData')) && 
           !preg_match('/login/', $request->pathinfo())
        ) {
            // 没登录就重定向
            return redirect((string)url('login/index'));
        }
        return $next($request);
    }

    // 后置中间件
    // public function handle($request, \Closure $next)

分页

https://www.kancloud.cn/manual/thinkphp6_0/1037638

ThinkPHP内置了分页实现，要给数据添加分页输出功能变得非常简单，可以直接在Db类查询的时候调用paginate方法：

// 查询状态为1的用户数据 并且每页显示10条数据
$list = Db::name('user')->where('status',1)->order('id', 'desc')->paginate(10);

// 渲染模板输出
return view('index', ['list' => $list]);

模板文件中分页输出代码如下：

<div>
<ul>
{volist name='list' id='user'}
    <li> {$user.nickname}</li>
{/volist}
</ul>
</div>
{$list|raw}

默认情况下，生成的分页输出是完整分页功能，带总分页数据和上下页码，分页样式只需要通过样式修改即可。如果你需要单独获取总的数据，可以使用

// 查询状态为1的用户数据 并且每页显示10条数据
$list = Db::name('user')->where('status',1)->order('id' ,'desc')->paginate(10);
// 获取总记录数
$count = $list->total();
return view('index', ['list' => $list, 'count' => $count]);

支持传入总记录数而不会自动进行总数计算，例如：

// 查询状态为1的用户数据 并且每页显示10条数据 总记录数为1000
$list = Db::name('user')->where('status',1)->paginate(10,1000);
// 获取分页显示
$page = $list->render();

return view('index', ['list' => $list, 'page' => $page]);

模板中渲染一样：

<div>
<ul>
{volist name='list' id='user'}
    <li> {$user.nickname}</li>
{/volist}
</ul>
</div>
{$page|raw}

对于UNION查询以及一些特殊的复杂查询，推荐使用这种方式首先单独查询总记录数，然后再传入分页方法

如果你仅仅需要输出一个 仅仅只有上下页的分页输出，可以使用下面的简洁分页代码：

// 查询状态为1的用户数据 并且每页显示10条数据
$list = Db::name('user')->where('status',1)->order('id', 'desc')->paginate(10, true);

// 渲染模板输出
return view('index', ['list' => $list]);

由于简洁分页模式不需要查询总数据数，因此可以提高查询性能。
