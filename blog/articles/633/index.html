无限极

在一个有明确的归属顺序的数据表中，比如商品表、题库章节表、用户权限表等，比如商品啤酒是总类，下面有青岛啤酒、哈尔滨啤酒等，可以使用无限极的方式，将多维数组拼成一个一维数组。

数据表讲解

这里parent_id 指代父类，从属于该0分类的子类，其的parent_id均指向父类的id，关系如下：

0（根，虚拟顶层）
│
├─ id=1  友情链接列表        (parent_id=0)
│   ├─ id=2  添加            (parent_id=1)
│   └─ id=3  修改            (parent_id=1)
│
├─ id=4  搜索关键字列表      (parent_id=0)
│   └─ id=5  搜索添加        (parent_id=4)
│
├─ id=6  订单列表            (parent_id=0)
│   ├─ id=12 订单添加        (parent_id=6)
│   ├─ id=13 订单修改        (parent_id=6)
│   └─ id=14 订单删除        (parent_id=6)
│
├─ id=7  系统管理            (parent_id=0)
│   （无子节点）
│
└─ id=8  商品列表            (parent_id=0)
    ├─ id=9  商品添加        (parent_id=8)
    ├─ id=10 商品修改        (parent_id=8)
    └─ id=11 商品删除        (parent_id=8)

构建排序模型

新建一个权限模型，路径：app/common/model/AuthRule.php

<?php
namespace app\common\model;

use think\Model;

class AuthRule extends Model
{
    // 指定数据表的名称
    // protected $name = 'auth_rule';
    // 无限极分类实现方法
    // 将数据表数据 清洗成parent_id=0的是第一个元素，下面的元素显示指向parend_id=0的父元素id的形式
    // $level作用就是可以通过level实现 前面的小横杆 echo str_repeat('-', $vo['level']*6) 实现层级
    // str_repeat 是将第一个参数字符重复 N次
    public function sort($ruleRes, $parent_id = 0, $level = 0)
    {
        static $arr = array();
        foreach($ruleRes as $k => $v) {
            if($v['parent_id'] == $parent_id) {
                $v['level'] = $level;
                $arr[] = $v;
                $this->sort($ruleRes, $v['id'], $level + 1);
            }
        }

        return $arr;
    }

    /*
    public function childrenids($ruleid)
    {
        通过模型获取数据 把$this想象成Db::name(xxx)就行
        $data = $this->field('id, parend_id')->select();
        return $this->_childrenids($data, $ruleid);
    }
*/
}

  • static修饰的变量在整个函数调用生命周期内只初始化一次，多次递归调用共享同一个$arr。

  • 它不会因为递归调用而重置，所以递归过程中不断往同一个$arr里push数据。

$level的作用

就是记录当前节点在第几层，根节点level = 0，子节点level = 1，孙节点level = 2……

模板里用它来控制缩进，比如：

echo str_repeat('-;', $vo['level'] * 6);

控制器中引用排序

因为本例是一个tp6的多应用模式，所以控制器在app/qingadmin/controller/AuthRule.php

<?php
namespace app\qingadmin\controller;

use app\BaseController;
use app\common\model\User;
use think\facade\Db;
use think\facade\View;
use think\facade\Request;
// 不起别名 模型的Authrule与控制器名字冲突就会报错
use app\common\model\AuthRule as AuthRuleModel;

class AuthRule extends Base
{
    public function index()
    {
        // 所有数据
        $ruleData = Db::table('auth_rule')
                            ->select()
                            ->toArray();

        // 进行格式化 按照parend_id 将所有 分类实现 无限极分类 
        // 从parent_id=0是第一个元素，然后后面的属于0的项就指向0的id，最终实现一个一维数组
        $AuthRuleModel = new AuthRuleModel();
        $ruleDataTree = $AuthRuleModel->sort($ruleData);
        // halt($ruleDataTree);
        // 将数据渲染到app\qingadmin\view\admin 的模板中
        return view('admin/authrule', [
            'ruleDataTree' => $ruleDataTree
        ]);
       
    }
}

执行过程逐步推演

第 1 次调用

sort($ruleData, $parent_id = 0, $level = 0)

static $arr = []初始化（空数组）。

遍历$ruleRes全部 14 条数据，找parent_id == 0的：

id=1 友情链接列表 → 匹配

  • $v['level'] = 0

  • $arr[] = $v→arr = [1]

  • 递归调用sort($ruleRes, 1, 1)← 关键，先处理完 1 的所有子孙再继续循环

id=4 → 等 1 的递归全部返回后才轮到它，id=6、id=7、id=8 → 依次处理

第 2 次调用（递归处理 id=1 的子节点）

sort($ruleRes, $parent_id = 1, $level = 1)

此时$arr里已经有[1]了（static 共享）。

遍历全部数据，找parent_id == 1的：

id=2 添加 → 匹配

  • $v['level'] = 1

  • $arr[] = $v→arr = [1, 2]

  • 递归sort($ruleRes, 2, 2)→ 没有任何数据的 parent_id=2，直接返回（什么都不加）

id=3 修改 → 匹配

  • $v['level'] = 1

  • $arr[] = $v→arr = [1, 2, 3]

  • 递归sort($ruleRes, 3, 2)→ 返回空

这个调用返回后，回到第 1 次调用，继续 for 循环。

回到第 1 次调用，继续遍历

id=4 搜索关键字列表 →parent_id == 0匹配

  • $v['level'] = 0

  • arr = [1, 2, 3, 4]

  • 递归sort($ruleRes, 4, 1)

第 3 次调用（递归处理 id=4 的子节点）

parent_id = 4, level = 1

id=5 搜索添加 → 匹配

  • $v['level'] = 1

  • arr = [1, 2, 3, 4, 5]

  • 递归sort($ruleRes, 5, 2)→ 空返回

回到第 1 次调用，继续

id=6 订单列表 → 匹配

  • $v['level'] = 0

  • arr = [1, 2, 3, 4, 5, 6]

  • 递归sort($ruleRes, 6, 1)→ 里面会依次加入 12、13、14，level 都是 1

  • id=7 系统管理 → 匹配，level=0，无子节点 →arr 加 7

  • id=8 商品列表 → 匹配，level=0 → 递归加入 9、10、11

最终结果

[1(level0), 2(level1), 3(level1),
 4(level0), 5(level1),
 6(level0), 12(level1), 13(level1), 14(level1),
 7(level0),
 8(level0), 9(level1), 10(level1), 11(level1)]

模板里循环这个数组，用str_repeat('-', $v['level']*6)就能显示成树：

友情链接列表
------添加
------修改

------搜索添加

------订单添加
------订单修改
------订单删除
系统管理
商品列表
------商品添加
------商品修改
------商品删除

一句话概况思路

从parent_id=0开始，找到一个父节点就先把它放进结果数组，然后立刻递归去找它的所有子节点（深度优先），子节点找完再回来继续找下一个同级父节点。level只在每次递归时 +1，用来标记层级。

当然这段代码还是有问题，还可以优化空间，这里只是提供思路。
