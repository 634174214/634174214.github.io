按钮边框滚动动画的实现原理

5179次阅读 312人点赞 作者: WuBin 发布时间: 2021-11-22 11:21:39
扫码到手机查看

实现简介

关于button的，无论是样式还是动画，各路大神都在分享这自己的创意，而在button动画中，边框滚动的效果，我觉得是最好的。虽说是button的动画，其实这种动画效果，不仅仅局限在button上。在边框滚动动画上，主要是有下面三种：

  • 单边
  • 双边
  • 四边扩散

这三种边框滚动动画，

  1. 本人都是利用伪元素::after和::before实现的，当然也可以不用伪元素，套一层div， 不过我个人觉得比较复杂，考虑的也比较多。

  2. 这里button的边框不是利用border实现的，而是利用box-shadow实现的，因为在保证button和:after/before创建的，可以和按钮宽高保持一致。如果使用border的话，不小心的话，滚动的边框就会在在里面。

单边边框滚动

效果如上，当鼠标放在button，会从一个角出发，经过一圈，最终回到出发角。这里动画正好是一个圈，正好用到了after和before。看上去可能有点难，但其实很简单：这里其实只要控制after的宽度和高度从0到100到100%就可以了呀。

可以先来看一下实现后的效果，点击查看。

初始状态：after和before都是宽高为0的，并且border是透明的，

  button::before,
  button::after {
      box-sizing: inherit;
      content: "";
      position: absolute;
      width: 0;
      height: 0;
      border: 2px solid transparent;
}
如何保证绕一圈，两个伪元素的定位肯定是不相同的，并且绕圈的动画，是一个负责一半，右下角就是分界线。
button::before {
top: 0;
left: 0;
}
button::after {
bottom: 0;
right: 0;
}
又因为边框指一条边一条边变化的，所以我们主要设置好动画延迟就可以了。
button:hover::before,
button:hover::after {
width: 100%;
height: 100%;
}
button:hover::before {
border-top-color: #60daaa;
border-right-color: #60daaa;
transition: width 0.25s , height 0.25s  0.25s;
}
button:hover::after {
border-bottom-color: #60daaa;
border-left-color: #60daaa;
transition: border-color 0s  0.5s, width 0.25s  0.5s,
height 0.25s  0.75s;
}
transition: width 0.25s, height 0.25s 0.25s; 意思是：宽度动画执行0.25秒，高度变化动画执行0.25s 并且高度动画延迟0.25s执行（延迟意思为等待宽度变化完再执行动画）

双边

这个动画算是上一个动画的升级版，不过我觉得从代码层面更简单了。

我们只需要更改两个地方,将两者的定位统一：

可以先来看一下实现后的效果，点击查看。

button::after,
button::before 
{
   top: 0;
   left: 0;
}

将下面的动画更改，先增高度再曾宽度。

button:hover::after {
   border-bottom-color: #60daaa;
   border-left-color: #60daaa;
   transition: height 0.25s , width 0.25s 0.25s;
}

四边扩散

乍一看，挺麻烦，四条边都是从中点往两边扩散，首先我们针对这个中间会想到的是 transform-origin: center;，这个属性可以改变元素的位置，那么此时在解决另一个问题，往两边扩散，我一开始想到的是width从0到100%，但是这个 transform-origin: center;好像没法用了。我依稀记得再加上一个属性，可以生效，但是我就是记不起来了！于是我转到了另一个属性scale*，只要我一开始设置为0，后面设置为1 不就可以了。

可以先来看一下实现后的效果，点击查看。

我分解上边和下面，效果如下：

button::before {
        border-top: 2px solid #60daaa;
        border-bottom: 2px solid #60daaa;
        transform: scale3d(0, 1, 1);
}
button:hover::before {
    transform: scale3d(1, 1, 1);
    transition: transform 0.5s;
}
