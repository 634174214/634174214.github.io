可以随意切换node版本的工具nvm

nvm的安装

大家在开发过程中，不知道有没有遇到过node已经安装好了，npm也有了，但是运行项目的时候就是莫名奇妙的报了很多看不懂的错误。这个时候大家不加思索的打开了度娘。结果显示您的node版本过高或者过低。需要重新卸载安装别的版本，就特别搞心态。那么今天我就为大家说一下我自己的方法。（NVM=NodeJS Version Management）

修改nvm镜像（永久生效）

# 1. 设置 node 镜像（淘宝 npmmirror）
nvm node_mirror https://npmmirror.com/mirrors/node/

# 2. 设置 npm 镜像
nvm npm_mirror https://npmmirror.com/mirrors/npm/

# 3. 清缓存（非常重要）
nvm cache clear

把现在安装的node卸载

打开cmd，输入系统中node还没有有存在。

node -v

下载nvm

https://github.com/coreybutler/nvm-windows/releases  下载第四个安装包。

预防被墙，特意下载后传入百度网盘一份，有需要的自取，里面是1.1.10版本的nvm安装程序，有安装版和绿色版，可以根据自身情况选择使用：

https://pan.baidu.com/s/1OlbOhf0hetQ9LlCcpn1u5A?pwd=dmjp 提取码:dmjp
安装的时候最好在D盘里面创两个新文件，一个用来存放nvm，一个用来存放以后下载的node

安装

这里需要注意的是如果安装在C盘一般会有权限问题, 所以最好不要装在C盘，例如D:\nvm 和 D:\nodejs 即可。

（注意路径中不能包含中文或空格，不然在nvm use命令会报乱码错误。）

在安装nvm的时候，第一个路径改成自己刚创建的nvm，第二个路径改成自己刚创建的node文件夹。

选择存放node的路径

然后一路next，然后install，最后finish完成安装。

确认安装成功

在cmd中，输入命令nvm。

如果出现一大串信息，Running version 1.1.10.之类的版本信息，就代表安装成功了。

配置下载的镜像

安装好后在D:\nvm\nvm里对settings.txt文件配置，（主要是若不能科学上网下载速度太慢了，分别配置node和npm的下载镜像）

root: D:\worksoft\nvm\nvm
path: D:\worksoft\nodejs
node_mirror: https://npmmirror.com/mirrors/node/
npm_mirror: https://npmmirror.com/mirrors/npm/

下面的信息已经过期了，淘宝 npm 镜像（npm.taobao.org）已停止服务，目前官方推荐使用npmmirror.com替代。

如果执行nvm list available 发现列表为空，那么代表当前镜像域名不可用。

root: D:\nvm\nvm
path: D:\nodejs
node_mirror: http://npm.taobao.org/mirrors/node/
npm_mirror: https://npm.taobao.org/mirrors/npm/

nvm的使用

可以先看看目前node有拿一些版本：

https://nodejs.org/en/download/releases/

https://nodejs.org/dist/

https://help.aliyun.com/document_detail/60811.html （上面链接打不开的时候可以参考）

NVM要以管理员身份运行cmd，不然在nvm use node_version时会报乱码错误。

查看远程可安装的node版本

可以先查看远程可安装的node版本（除开所显示的其他版本也可以下载）

nvm list available

可选参数available显示所有可下载版本，缺省时显示本地安装的所有版本及当前使用的node版本。

下载指定的node版本并使用

下载node版本的命令为nvm install (版本号) 括号省略。比如：

nvm install 12.18.1

下载完后，你可以查看目前所下载的所有node版本。使用：

nvm list

例如，现在项目用的是12.18.1，那么使用这个版本的node命令就是：

nvm use12.18.1

即可。同时可以查看npm和node版本是否正确。

在cmd中分别直接输入：

npm -v 和 node -v

重新安装vue-cli

注意，全局安装的 vue-cli（使用npm install -g @vue/cli）：

  • 切换 Node 版本后，原来的全局 vue-cli 可能无法直接使用
  • 需要在新切换的 Node 版本下重新全局安装 vue-cli
  • 建议切换 Node 版本后，先运行vue --version检查是否能正常使用，若提示命令不存在或报错，再重新安装即可。

确认当前 Node 版本是否正常运行

node -v 和 npm -v，确保 Node 和 npm 能正常工作。若版本显示正常，继续下一步。

重新全局安装 vue-cli

在当前 Node 版本下执行命令：

npminstall -g @vue/cli

验证安装

安装完成后，再次运行vue --version，若显示版本号，则说明安装成功。

常用命令总结

  • nvm list available：可选参数available显示所有可下载版本，缺省时显示本地安装的所有版本及当前使用的node版本。
  • nvm install 14.18.1：安装14.18.1版本的nodejs及对应的npm，会在nvm的安装目录下生成对应版本的nodejs文件夹，可选参数arch指定安装系统位数(32位/64位，默认根据系统位数)。
  • nvm use 14.18.1：使用指定版本的nodejs和对应npm，如果不使用管理员身份运行cmd，此时此处会出现exit status 1: …的乱码错误，可选参数arch指定安装系统位数(32位/64位，默认根据系统位数)。
  • nvm uninstall 14.18.1：卸载对应版本的nodejs，nvm的安装目录中对应文件夹会去掉。
  • nvm arch：显示node运行系统环境32位或64位。
  • nvm on：开启nodejs版本管理。
  • nvm off：关闭nodejs版本管理。
  • nvm proxy [url]：设置下载代理，可选参数url，不加参数显示当前的代理，url为none则清除当前代理。
  • nvm node_mirror [url]：设置node镜像，默认为https://nodejs.org/dist/，设置后可在nvm安装目录下settings.txt文件查看。
  • nvm npm_mirror [url]：设置npm镜像，默认为https://github.com/npm/cli/archive/，同理设置后可在nvm安装目录下settings.txt文件查看。
  • nvm root [path]：设置存储nodejs的目录，默认在nvm的安装目录下。
  • nvm version：查看nvm版本。
  • nvm cache clear 清除 nvm 缓存，当修改setting.txt文件时，需要清空一下缓存。
  • nvm root  找nvm的安装目录
