npm常用命令解析

3475次阅读 241人点赞 作者: WuBin 发布时间: 2022-04-12 15:22:21
扫码到手机查看

npm 常用的安装命令

npm i             就是npm install 简写
npm i xxx -D      就是 npm i xxx --save-dev
npm i xxx -S      就是 npm i xxx --save
npm i xxx -g      就是 全局安装
npm i xxx         就是 npm i xxx --save
npm uninstall xxx 卸载xxx包

命令参数详解

pm i xxx --save-dev 是把依赖写入进devDependencies对象里面

npm i xxx --save 是把依赖写入进dependencies对象里面

npm i xxx -g 就是安装到全局下，在命令行的任何地方都可以操作，不会提示“命令不存在等错误”

依赖和开发时依赖

devDependencies 是开发环境下的依赖，这里是开发环境下的依赖，上线后非必需，比如：webpack，gulp等压缩打包工具.

dependencies 是生产环境下的依赖，项目刚需的依赖在这里，比如UI框架，字体文件等线上必需的东西.一般这个配置在package.json文件中.

npm 5.0.0 之前，有 --save 参数才会把模块写入到 packages.json。现在已经是内置参数，不用额外写了。
