点击a标签实现QQ对话、邮件发送、拨打电话功能

6139次阅读 360人点赞 作者: WuBin 发布时间: 2021-11-05 09:44:42
扫码到手机查看

a标签实现QQ弹窗对话

代码出奇的简单，本以为还要调用JS之类，发现只需要一个a标签：

<a href="tencent://message/?uin=634174214&Site=/&Menu=yes">
点我打开QQ聊天界面
</a>

但是注意，自己跟自己是无法聊天的。QQ会有弹窗提示。

大家可以点击右侧的“交流”进行尝试，欢迎骚扰~~

a标签实现邮件发送

<a>标签还有一个作用是可以链接Email地址，使用mailto能让访问者便捷向网站管理者发送电子邮件。我们还可以利用mailto做许多其它事情。下面一一进行讲解，请看详细图示：

注意：如果mailto后面同时有多个参数的话，第一个参数必须以“?”开头，后面的参数每一个都以“&”分隔。

下面是一个完整的实例(href要在一行上)：

<a href="mailto:wubin-work@qq.com
        ?cc=chaosong@qq.com
        &bcc=misong@qq.com
        &subject=邮件标题
        &body=邮件内容">
    告诉我们
</a>

当然经过测试，在chrome的PC端上上没什么用，其可以用于手机端，在手机端会有默认的弹窗出现~

手机端拨打电话、发短信、发送自己位置

 //点击后直接拨打10086
<a href="tel:10086">10086</a>
 
//点击后直接给10086发信息，消息内容默认为message_body
<a href="sms:10086?body=message_body">给 10086 发短信</a>
 
//点击后直接发送自己的位置
<a href="geopoint:116.281469,39.866035">我的位置</a>
