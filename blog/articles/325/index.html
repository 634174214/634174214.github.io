PHP中根据某一键值对多维数组进行排序的方法

本文实例讲述了PHP编程实现多维数组按照某个键值排序的方法。分享给大家供大家参考。

实现对多维数组按照某个键值排序的两种解决方法(array_multisort和array_sort):

array_multisort

array_multisort()函数对多个数组或多维数组进行排序。

比如，对数组$hotcat按照count键值大小降序进行排序：

$hotcat =array(

   array('1501'=>array('catid'=>'1546','catname'=>'数组排序 一级','count'=>'588')),

   array('1502'=>array('catid'=>'1566','catname'=>'数组排序二级','count'=>'688')),

   array('1503'=>array('catid'=>'1846','catname'=>'数组排序 三级','count'=>'598'))

);
//提取列数组；
foreach ($hotcat as $key => $val) {
    $tmp[$key] = $row['username'];
}

// 此处对数组进行降序排列；SORT_DESC按降序排列
// SORT_ASC - 默认。按升序排列 (A-Z)。
// SORT_DESC - 按降序排列 (Z-A)。
array_multisort($tmp, SORT_DESC, $hotcat);

自定义函数array_sort

自定义方法array_sort()进行排序，并指定数组以$keys键值排序

/**
 * [array_sort 多维数组按照某一键值排序函数]
 * @Author   wubin
 * @DateTime 2022-11-15T10:20:19+0800
 * @param    [array]                   $array [为要排序的数组]
 * @param    [string]                  $keys  [为要用来排序的键名]
 * @param    string                    $type  [默认为升序排序]
 * @return   [array]                          [返回排序好的数组]
 */
function array_sort($array, $keys, $type = 'asc'){
    $keysvalue = $new_array = array();
    foreach ($array as $k=>$v){
        $keysvalue[$k] = $v[$keys];
    }

    if($type == 'asc'){
        asort($keysvalue);
    }else{
        arsort($keysvalue);
    }
    reset($keysvalue);

    foreach ($keysvalue as $k=>$v){
        $new_array[$k] = $array[$k];
    }

    return $new_array;
}

使用时，参考：

//此处对数组进行降序排列
$hot_cat = array_sort($hot_cat, 'count', 'desc');

对$hot_cat数组按照count键值进行排序：降序排列。

第一种方法有个弊端,如果你的数组如果是字符串键名将被保留,但是数字键将被重新索引,从0开始,并以1递增。所以当数组排序之后并且需要保留之前的所有键名的话,那就推荐使用第二种方法。【具体使用时候，建议亲自尝试一下，打印下结果看看。】
