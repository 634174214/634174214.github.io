vue-cli初始化一个项目

11732次阅读 298人点赞 作者: WuBin 发布时间: 2021-03-18 17:21:12
扫码到手机查看

进入到项目目录

更详细的项目初始化方法请参考：Vue3.0基础项目的创建【配合gitee】

首先先进入到项目文件夹下，比如我的项目文件夹是e:/code/xin-zt/

// cmd
C:\Users\Bin  e:
E:\code cd xin-zt

然后在e:/code/xin-zt/下新建文件夹backend。

注意，当新建了文件夹的时候，就不要进入到 cd code/xin-zt/backend下执行vue create backend的命令了,那样会在xin-zt/backend/下再新建一个backend的文件夹，所以如果新建了backend的目录，仅仅在cd code/xin-zt  下执行 vue create backend的命令即可。那样所有的文件都会直接在backend的目录下。

全局安装vue-cli

每次初始化vue项目的总是记不住初始化的命令，新版本更新了很多语句，像之前的vue webpack init是初始化老版本的项目的。。在这里特此记录一下vue 2和3如何初始化项目。

首先是官方地址：vue-cli官网首先是全局安装

npminstall -g @vue/cli

如果之前起项目的时候安装过了，就不用再安装一次了，如果能查看到版本号，证明就安装过了。

vue--version

初始化项目

使用以下命令初始化一个vue项目：

vue create backend

如图，会让你选择是使用vue2还是vue3，将来如果哪一天没有vue2的选项了也不要奇怪，早晚会被淘汰掉的。。能用3还是用3吧！（截止到2021年3月18日 还是这个界面）。

一般推荐 Default即可，因为设置都可以在初始化项目后进行更改。

特别特别注意第一条，如果新建了子目录children,直接在father目录下执行 vue create children即可；如果没有新建children目录，那么也是在father目录下执行，会自动生成一个children的文件夹。

还有一些vue.config.js文件的配置，等有机会再讲吧~~
