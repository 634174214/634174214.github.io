万能提示词

通用完整版（推荐，绝大多数 PHP 业务直接粘贴）

请基于【PHP 8.1 + Laravel10 / ThinkPHP6】编写PHP代码，严格遵守下面全部约束：
1. 遵循PSR‑1、PSR‑12编码规范，代码注释完整清晰；
2. 所有用户传入参数必须做参数校验、过滤，禁止直接使用原始$_GET/$_POST；
3. 禁止直接拼接SQL字符串，数据库操作强制使用参数绑定/框架ORM预编译；
4. 权限判断、身份校验必须使用强全等 ===，禁止使用 == 松散比较；
5. eval、unserialize、exec、system等高风险函数非必要不使用，如果必须使用，必须增加严格白名单过滤，并标注风险说明；
6. 增加完整try‑catch异常捕获，记录业务错误日志，不直接对外暴露原始错误信息；
7. 处理空值、null、0、空字符串等边界场景，区分业务含义，禁止无脑使用empty()；
8. 文件上传逻辑必须校验真实文件头、MIME，不能仅校验后缀，上传目录禁止执行脚本；
9. 敏感配置、密钥、数据库密码全部使用环境变量读取，禁止硬编码到业务代码；
10. 返回工业级可审核的草稿代码，输出结束后列出这份代码存在的潜在风险点。

高危漏洞避坑清单

打印 / 存备忘录，复制 AI 代码逐项对照✅需要检查｜❌禁止出现

数据库相关

[❌] 禁止直接拼接用户变量到 SQL 语句，哪怕是数字也不要直接拼接
[✅] 所有查询、更新、删除，全部使用参数绑定 / ORM 预编译
[✅] 业务 ID、条件字段，做类型强制转换，不要直接接收外部参数
[✅] 事务操作必须处理回滚，增加异常捕获
[❌] 禁止直接把用户输入当做字段名、排序字段传入 SQL

权限与业务校验

[❌] 权限判断不要使用 == 松散比较，必须使用 ===
[✅] 所有接口必须做身份、权限校验，不要相信前端传来的权限标记
[✅] 接口必须校验操作者和操作数据的归属关系，防止越权
[✅] 接口返回不要泄露数据库原始字段、用户敏感信息

文件上传 & 文件操作

[❌] 不能只校验文件后缀名
[✅] 校验文件 MIME 类型、文件头，二次检测真实文件类型
[✅] 上传目录设置禁止执行 PHP 脚本，文件重命名，不要使用用户原始文件名
[❌] file_put_contents、unlink 等文件操作，入参不能直接来自用户可控输入

高危函数黑名单

如必须使用，必须加白名单过滤，并且写风险注释eval()、unserialize()、exec()、system()、passthru()、popen()

参数与空值判断

[❌] 不要无脑 empty () 判断，0、null、''、[] 业务含义不一样
[✅] isset 判断变量是否存在；=== null 判断是否为空；业务区分 0 值
[✅] 接口入参提前做格式校验，数字、字符串、数组做类型约束

敏感信息

[❌] 数据库密码、支付密钥、salt、token，禁止硬编码写死代码
[✅] 全部读取.env 环境变量配置
[❌] 错误日志、接口返回不要打印密钥、密码明文

异常与日志

[✅] 数据库调用、第三方接口调用必须 try‑catch
[✅] 捕获异常记录日志，对外返回统一友好错误码，不要抛出原始 PHP 报错
[❌] 不能吞掉异常不记录日志，否则线上故障完全无法排查

框架 & 版本兼容

[✅] 确认 AI 输出代码适配你的 PHP 版本、框架版本
[❌] 不要直接复制高版本 PHP 语法到低版本环境运行

AI 代码上线前必做 4 步

人工复核数据库、文件、权限、高危函数相关代码
静态检测工具扫描 PHPStan / Psalm
边界测试：空参数、特殊字符、非法参数
AI 生成代码只作为草稿，人工修改后再提交仓库

模板 3：文件上传安全示例 ThinkPHP6

<?php
/**
 * 图片安全上传示例
 */
public function upload()
{
    $file = $this->request->file('file');
    if(!$file){
        return json(['code'=>400,'msg'=>'请上传文件']);
    }
    //限制文件大小
    $sizeLimit = 2*1024*1024;
    if($file->getSize() > $sizeLimit){
        return json(['code'=>400,'msg'=>'文件过大']);
    }
    //真实文件类型校验，不只判断后缀
    $allowMime = ['image/jpeg','image/png','image/gif'];
    $mime = $file->getMime();
    if(!in_array($mime,$allowMime)){
        return json(['code'=>400,'msg'=>'仅允许图片']);
    }
    //文件重命名，不使用原始文件名
    $saveName = \think\facade\Filesystem::disk('public')->putFile('upload',$file);
    return json(['code'=>200,'data'=>['path'=>$saveName]]);
}

模板 4：接口异常捕获 + 日志示例

<?php
use think\facade\Log;

public function getUserInfo()
{
    try {
        $id = (int)$this->request->get('id',0);
        if($id <=0){
            return json(['code'=>400,'msg'=>'参数非法']);
        }
        $info = \app\model\User::where('id',$id)->find();
        if(!$info){
            return json(['code'=>404,'msg'=>'用户不存在']);
        }
        return json(['code'=>200,'data'=>$info]);
    }catch (\Exception $e){
        Log::error('获取用户信息异常：'.$e->getMessage().' | '.$e->getTraceAsString());
        return json(['code'=>500,'msg'=>'系统繁忙，请稍后再试']);
    }
}
